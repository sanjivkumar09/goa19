        HOW TO ACCESS THE 5D GAME - STEP BY STEP
═══════════════════════════════════════════════════════════

⚠️ IMPORTANT: The /5d page requires you to be LOGGED IN!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📝 CORRECT STEPS TO ACCESS 5D GAME:

STEP 1: Make sure server is running
   ✓ Server is currently running on port 3000

STEP 2: Open your browser
   • Use Chrome, Firefox, or Edge
   • Make sure cookies are enabled

STEP 3: Log in to your account FIRST
   Go to: http://localhost:3000/login
   
   Enter your credentials:
   • Username/Phone
   • Password
   • Click "Login"

STEP 4: After successful login, access 5D game
   Go to: http://localhost:3000/5d
   
   ❌ WRONG: http://localhost:3000/5d/+
   ✅ CORRECT: http://localhost:3000/5d

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔴 COMMON MISTAKES:

1. ❌ Typing wrong URL: /5d/+ (extra slash and plus)
   ✅ Use: /5d (clean URL)

2. ❌ Not being logged in
   ✅ Always log in first at /login

3. ❌ Using old cached pages
   ✅ Clear cache: Ctrl + Shift + Delete

4. ❌ Cookies disabled
   ✅ Enable cookies in browser settings

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🧪 TEST YOUR ACCESS:

Option 1: Use the diagnostic tool
   Open: test-5d-access.html (in your browser)
   
Option 2: Test manually
   1. Go to: http://localhost:3000/login
   2. Log in with your account
   3. Go to: http://localhost:3000/5d
   4. Game should load!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔍 TROUBLESHOOTING:

Problem: "Cannot GET /5d" or blank page
Solution: Make sure you're logged in first

Problem: Redirects to login page
Solution: This is normal - log in, then access /5d again

Problem: Page loads but shows error
Solution: Check browser console (F12) for JavaScript errors

Problem: "Connection refused"
Solution: Start the server with start-server.bat
