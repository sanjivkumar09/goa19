→ Node.js version: 18.x or 20.x
→ Click "Create Application"

🐛 QUICK TROUBLESHOOTING
================================================================================

"Cannot connect to database"
→ Verify .env file was uploaded
→ Check database exists in phpMyAdmin
→ Verify goa.sql was imported successfully

"Module not found" error
→ Wait for npm install to complete (can take 5-10 minutes)
→ Or run manually via SSH: cd public_html && npm install

"502 Bad Gateway"
→ Restart Node.js application in Hostinger panel
→ Check Node.js version is 18.x or higher

Application won't start
→ Verify src/server.js path is correct
→ Check error logs in Node.js manager
→ Ensure all files uploaded correctly
